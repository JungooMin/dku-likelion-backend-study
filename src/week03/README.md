# week03 학습 내용

## 학습 주제
회원가입 프로그램 작성

## 학습 내용
- Java의 조건문과 반복문을 활용하여 회원가입 진행 여부를 입력받았다.
- Scanner를 사용하여 사용자로부터 ID, 비밀번호, 이름, 생년월일, 이메일을 입력받았다.
- 비밀번호와 비밀번호 확인 값이 일치하는지 검사하는 기능을 구현하였다.
- 생년월일이 6자리인지 확인하여 잘못 입력한 경우 다시 입력하도록 하였다.
- HashMap을 사용하여 한 명의 회원 정보를 저장하였다.
- ArrayList를 사용하여 여러 명의 회원 정보를 저장할 수 있도록 구성하였다.
- equalsIgnoreCase()를 사용하여 대소문자 구분 없이 Y/N 입력을 처리하였다.

## 실행 흐름
1. 회원가입 진행 여부를 입력받는다.
2. Y를 입력하면 회원가입을 진행한다.
3. ID, PW, 성명, 생년월일, 이메일을 입력받는다.
4. 비밀번호가 일치하지 않으면 다시 입력받는다.
5. 생년월일이 6자리가 아니면 다시 입력받는다.
6. 입력받은 회원 정보를 저장하고 가입 완료 메시지를 출력한다.
7. 추가 회원가입 여부를 묻고, Y이면 반복하고 N이면 종료한다.

## 느낀 점
이번 실습을 통해 Java의 기본 문법을 실제 프로그램에 적용하는 방법을 익힐 수 있었다. 특히 조건문, 반복문, Scanner 입력, ArrayList, HashMap을 함께 사용하면서 회원가입 프로그램의 전체 흐름을 이해할 수 있었다.
